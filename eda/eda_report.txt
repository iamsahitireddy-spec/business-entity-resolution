7. ACTIONABLE RECOMMENDATIONS FOR TEAMMATES
--------------------------------------------------------------------------------
FOR SAHITI (BLOCKING & CANDIDATE GENERATION):
1. Country Partitioning: Hard-block on 'country'. Zero true matches cross country
   boundaries. Prunes 50-60% of search space with 100% recall retention.
2. Never block solely on address: ~3.3% of S2/S3 records have no address.
3. Never block on exact name string: Only 21.4% share exact normalized names.
4. Recommended: Multi-key blocking (name token shingle + 3-char prefix within country).

FOR HAJIRA (FEATURE ENGINEERING & MATCHING MODEL):
1. Name similarity features (Jaro-Winkler, Token Sort, Levenshtein, TF-IDF Cosine)
   are the most universal and reliable matching signals.
2. Address features must include an 'is_address_missing' binary indicator.
3. Street number / postal code token overlap is a crucial feature to distinguish
   between chains/branches sharing the same generic business name.
4. Macro F0.5 evaluation heavily penalizes false merges (false positives). Set
   high classification thresholds (e.g. >= 0.65) to protect singleton scores.
